# Brand and diagrams

The Cove DuckDB logo is an original vector asset: a duck over water, with three data strokes in its body. Teal represents storage and analysis; amber highlights the bill.

- `icon.svg`: square mark for avatars and icons.
- `logo-light.svg`: wordmark for light backgrounds.
- `logo-dark.svg`: wordmark for dark backgrounds.
- `architecture.svg`: native, editable SVG drawn from the same architecture specification.
- `promo.gif` / `promo.mp4`: one-minute product video (GIF: 960×540, silent, burned-in subtitles; MP4: 1920×1080 with English narration). The narration is AI-generated speech; the product screens are illustrative mock-ups of the Query Editor and Admin Console, and the query result is the [quickstart](../../examples/quickstart/README.md) output.

Keep the mark's proportions and do not replace it with the official DuckDB logo. The light/dark wordmarks are theme variants of the same identity.
